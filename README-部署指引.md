# Go 控制台部署指引

下载入口见 [README](README.md)。程序和新版界面合并在 `/usr/bin/daed`，不需要额外安装旧皮肤或独立 dae 程序。

## 已有 Go 安装

先备份程序、Go 数据目录、服务单元和 geodata，记录启动参数。按 CPU / 固件选择新包。安装包不包含设备数据库；现有 systemd 数据目录覆盖继续有效。安装后核对版本、服务状态、登录、接口、资源和绑定，再确认热重载和联网。

## 从 Rust 迁移

Rust 与 Go 数据库结构不同，不能仅替换程序后直接使用原数据目录。

1. 停止服务，备份 Rust 程序、完整数据目录、服务单元和 geodata，确认备份可读取。
2. 使用 `python3 backend/migrate-rust-state.py --help` 查看参数，将数据库迁移到独立 Go 数据目录，保留原数据库。
3. 为 Go 设置独立数据目录，移除 Rust 专用启动前后钩子，安装新程序并启动。
4. 核对账户、资源和绑定、日志、DNS/联网及连续重载。失败时停止 Go，恢复备份程序和原服务单元，再启动 Rust。

原密码通过兼容验证后转换为 Go 哈希；账户 ID 和 JWT secret 保留。浏览器旧 `/api` 端点自动迁移到 `/graphql`。

不要将数据库、JSON/dae 资源备份、订阅地址、节点链接、密码、令牌、迁移报告或实机截图提交到 GitHub。

## 日常更新

Geosite/Geoip 每天北京时间 04:00 成批验证、更新并自动重载。定时订阅成功更新后自动合并重载。手动编辑群组或运行配置时按顶栏提示应用。

接口边界和验证范围见 [后端说明](backend/README.md)。历史 Release 保留为版本归档。
